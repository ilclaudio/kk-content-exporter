# Security policy

## Supported versions

Only the latest released version of KK Content Exporter receives security fixes.
Versions below 1.0.0 are development versions and are not meant for production sites.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues, pull requests or support forums.
Report them privately through the "Report a vulnerability" button of the repository's
GitHub Security Advisories page, with a description of the problem, the steps to reproduce it
and the affected version.

You will receive an acknowledgement, and the fix will be released before the details are made
public.
